# 药单整理助手

一个 Windows 上的 Excel 药品清单去重、合并与重复统计小工具。界面为 Win11 Fluent 风格，支持浅色、深色和跟随系统。

当前版本：**1.1.1**

开源地址：<https://github.com/Wang-Nainai/drug-list-assistant>

## 功能

| 处理方式 | 分组规则 | 输出重点 |
| --- | --- | --- |
| **精简合并** | 只按药品名称分组，同名药品合并为一行 | 规格去重后汇总，保留重复次数和原始序号 |
| **精确统计** | 按「药品名称 + 药品规格」精确分组 | 序号、药品名称、药品规格、重复次数、原始位置 |

- **最小化恢复黑块**：修复 Windows 从最小化恢复窗口时，界面首帧短暂露出黑色背景的问题。

### 1.1 新增

- **表头自动识别**：在前 30 行里寻找表头，支持常见别名，例如 `编号`、`药品名`、`包装规格`。
- **手动列映射**：自动识别缺列时弹出列映射窗口，也可以随时点击「列映射」调整。
- **药名格式规范化**：自动处理全角/半角、括号、首尾空格和多余空白等安全差异。
- **疑似药名人工确认**：点击「药名核对」查看写法相近的药名；程序只提供候选，不会自动合并。候选会显示对应规格，默认不勾选。
- **重复明细工作表**：输出文件增加「重复明细」，列出重复组中的原始行、原始行号和常用附加字段。
- **处理汇总工作表**：输出文件增加「处理汇总」，记录源文件、工作表、处理模式、行数、重复组、可减少行、药名合并情况等。
- **预览筛选**：结果表格支持搜索药名/规格、只看重复项、按首次出现/重复次数/药名排序。
- **批量文件**：一次选择多个工作簿，按当前模式批量导出结果；勾选文件卡片右上角「批量全表」可处理所有工作表。
- **结果排序**：首次出现、重复次数降序、药名排序，导出和预览保持一致。
- **运行日志**：处理结果、异常和批量失败会记录到本地日志。

## 输入要求

Excel 表头必须包含以下三列（列名可以使用常见别名）：

- `序号`
- `药品名称`
- `药品规格`

支持 `.xlsx`、`.xls`、`.xlsm`。只读取数据，不会修改原始文件。

表头不一定是第一行：程序会自动寻找最可能的表头行。找不到时会提示并使用列映射窗口。

## 输出文件

结果保存为新的 `.xlsx` 文件，默认放在源文件同目录：

```text
原文件名_精简统计_日期_时间.xlsx
原文件名_重复统计_日期_时间.xlsx
```

工作簿包含：

1. **精简结果 / 统计结果**：主结果。
2. **重复明细**：只收录重复次数大于 1 的组，便于核对；没有重复项时不生成该表。
3. **处理汇总**：本次处理的参数和统计信息。

如果目标文件已存在，会自动加序号，不会覆盖。

## 药品安全说明

药名是高风险字段，程序采取保守策略：

- 只自动归并**格式差异**：全角/半角、括号、多余空格、零宽字符等。
- 不做拼音、错别字、别名、厂家、剂型的自动模糊合并。
- 「药名核对」只提供疑似候选，必须人工勾选确认后才会影响本次处理结果。
- 候选窗口会显示每个名称的条数和规格，勾选前请核对规格、厂家和实际药品。
- 手工药名合并只对当前打开的文件生效，切换文件或工作表后会重置。
- 批量文件模式只使用自动格式规范化，不会套用当前文件的手工药名合并。

## 其他说明

- 预览最多显示 300 行，导出文件始终是完整结果。
- 表格里的「重复次数」包含首次出现，所以重复组的总次数会大于可减少行数。
- 使用「精简合并」时，同名不同规格会合并为一行，规格用 `, ` 连接；如果规格本身包含英文/中文逗号，则改用 `；` 连接，避免歧义。
- 批量文件模式默认处理每个工作簿的**第一个工作表**；勾选文件卡片右上角「批量全表」后会处理所有工作表。多工作表导出时，文件名会额外带上工作表名。
- 批量全表会把没有数据或表头不完整的工作表列为「未处理」，不会中断其他工作表。
- 日志位置：`%LOCALAPPDATA%\DrugListAssistant\app.log`
- 设置位置：`%APPDATA%\DrugListAssistant\settings.json`

## 开发与打包

```powershell
pip install -r requirements.txt
python app.py
python -m unittest discover -s tests -v
python -m PyInstaller --noconfirm --clean DrugListAssistant.spec
```

打包产物为 `dist\药单整理助手.exe`，单文件、无控制台。当前版本未做代码签名，首次运行可能触发 Windows SmartScreen 提示。
